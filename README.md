## FreeTheAI

A free AI API and model marketplace behind one OpenAI-compatible endpoint. It has served **over 219 billion tokens across 7.5 million requests** ([public stats](https://freetheai.org/stats)).

I built and run the Go gateway. It handles keys and accounts, credits, rate limits, abuse controls, usage metering and routing by price or speed.

[freetheai.org](https://freetheai.org/) · [Docs](https://freetheai.org/docs) · [Status](https://freetheai.org/status)
